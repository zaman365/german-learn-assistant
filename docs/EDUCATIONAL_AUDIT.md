# Educational coverage audit — 23 September 2026

This is an agent review, not an independent German teacher's sign-off. The baseline was 89 lessons; the revised catalog has 100 lessons, five initial diagnostic rounds, 469 objectively scored course/diagnostic items, 139 lexical packages and 24 internal references. Counts describe scope, not validated proficiency or authentic exam difficulty.

## Method and scope

Inspected the complete catalog against COURSE_SPEC and every curriculum-map module, including later lessons rather than only each module's first lesson. Checked explanations, worked examples, vocabulary links, task prompts, assessment skill, exercise families, published rubrics, prerequisites and media dependencies. Reviewed all three mocks' first matching blocks and their four listening-matching conversations. The generated CONTENT_COVERAGE matrix records every lesson's objectives, exits, references and required sound; run `pnpm content:coverage` to reproduce it. `pnpm content:validate` checks referential/schema consistency.

For the changed material, checked German agreement, case government, lexical sense, negation scope, uncertainty and correspondence between source, answer and rationale. New text is original. No qualified independent reviewer or learner calibration panel participated. The review cannot certify C1 difficulty, natural recorded delivery or full curriculum adequacy.

## Evidence and version boundaries

Archived B2-10 v1 and all three original mock v1 payloads are seeded alongside new versions. A seed refuses a changed hash at an existing version; repeated seeding does not reset attempts. In-progress lessons and existing exams use their pinned versions. Historical evidence is evaluated against its own lesson version. Checkpoints use first attempts with the latest evaluation; a repeated or assisted answer cannot silently replace independent assessment.

Completion, a narrow repair, broad independent demonstration, seven-day retention and exam readiness remain distinct. Checkpoint profiles guide the next stage without barring suitable C1 learning or early exam section practice. Hard prerequisites apply only where explicitly authored; the remaining curriculum dependencies are recommendations and reference support, not a claim that every C1 objective was mastered.

## Remaining acceptance work

An independent German reviewer should assess every changed lesson and a stratified sample from each C1 module, then all mock texts, distractors, spoken roles and timing. Review the 12 course clips and 42 current mock clips after generation, and every complete 25-minute timeline. No audio was generated or approved in this pass. A first item-level failure should lead to an alternative unseen form; the finite authored bank does not promise unlimited independent retests. When exhausted, the app labels review as practice and preserves the remaining evidence need.
